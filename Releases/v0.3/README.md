# DeSpoilerize v0.3

Chrome Web Store release assets for DeSpoilerize v0.3.0.

## Highlights

- Added a dedicated World Cup 2026 football pack.
- Tuned World Cup spoiler wording for tournament state changes such as teams going through, topping groups, reaching knockout rounds, and penalty heartbreak.
- Removed the overly specific Coventry City selectable pack while keeping Coventry coverage in the broader Championship pack.
- Improved matching for accented team names.
